# Deep Learning Lab

A comprehensive deep learning laboratory containing multiple notebooks covering fundamental and advanced concepts in neural networks, computer vision, and natural language processing.

---

## Overview

This repository contains practical implementations and experiments in deep learning, organized as a series of Jupyter notebooks with detailed explanations, code examples, and visualizations. The labs cover foundational concepts as well as real-world applications using CNNs, RNNs, and LSTMs.

---

## Contents

The repository includes the following Jupyter notebooks:

- **lab 1.ipynb** – Introduction to deep learning fundamentals including neural network basics, activation functions, and foundational concepts.
- **lab 2.ipynb** – Advanced deep learning topics covering optimization techniques, advanced architectures, and practical applications.
- **lab 3.ipynb** – *Muffin vs Chihuahua Image Classification using CNN*: A Convolutional Neural Network (CNN) based image classification project to distinguish between muffins and chihuahuas using computer vision techniques.
- **lab 4.ipynb** – *Sentiment Analysis using RNN and LSTM*: Natural Language Processing (NLP) project implementing Recurrent Neural Networks (RNN) and Long Short-Term Memory (LSTM) networks for sentiment classification on text data.

---

## Features

The labs cover essential deep learning topics including but not limited to:

- Neural network fundamentals and architecture
- Activation functions and their properties
- Forward and backpropagation algorithms
- Optimization techniques (SGD, Adam, RMSprop, etc.)
- Loss functions and their applications
- Model training, validation, and evaluation
- Deep learning architectures (CNNs, RNNs, LSTMs)
- Image classification using CNNs
- Text processing and sentiment analysis
- Practical deep learning applications

## Lab Highlights

### Muffin vs Chihuahua Classification (CNN)

This project demonstrates:

- Image preprocessing and augmentation
- Building CNN architectures using TensorFlow/Keras
- Binary image classification
- Model training and performance evaluation
- Visualization of predictions and accuracy metrics

### Sentiment Analysis using RNN & LSTM

This project demonstrates:

- Text preprocessing and tokenization
- Sequence padding and embedding layers
- Implementation of Simple RNN and LSTM models
- Sentiment classification on textual datasets
- Performance comparison between RNN and LSTM architectures

## Requirements

To run these notebooks, you'll need:

- Python 3.7+
- Jupyter Notebook or JupyterLab
- NumPy
- Pandas
- Matplotlib
- TensorFlow / Keras
- Scikit-learn

Install dependencies with:

```bash
pip install jupyter numpy pandas matplotlib tensorflow scikit-learn
```
